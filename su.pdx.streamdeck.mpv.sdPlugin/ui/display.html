A Tera template. Write mpv property names with _ instead of -: time_pos, not time-pos (Tera reads - as minus). Use dots for sub-properties: metadata.title. A newline starts a second title line.

| time formats seconds as M:SS or H:MM:SS, and -- when unavailable. Other properties that may be missing (no file loaded) need | default(value="…"), or the key shows --.

Examples:

  • {{ time_pos | time }}
  • {{ duration | time }}
  • {{ time_remaining | time }}
  • {{ percent_pos | default(value=0) | int }}%
  • {{ media_title | default(value="") }}
  • {% if pause | default(value=false) %}paused{% else %}playing{% endif %}
  • {{ metadata.title | default(value="") }}

Empty shows {{ time_pos | time }}.
